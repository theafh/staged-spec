# spec_derive_intent

Analyze all documents in the `/specs` folder and produce the Project Intent Summary.

Use the spec_development Skill and follow its spec_intent reference for the intent structure and creation rules.

Create the file `specs/intent.md` and add a paragraph at the top of `specs/architecture.md` that summarizes what the project is about based on the intent findings, linking to `intent.md` for the full document.
