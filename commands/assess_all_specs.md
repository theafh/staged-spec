# assess_all_specs

Assess the spec framework as a whole for completeness, coherence, and readiness.

Use the spec_development Skill and follow its framework_assessment reference for assessment guidance.

Read all files under `/specs` — `architecture.md`, `intent.md`, `security.md`, `testing.md`, `features.md`, and every stage spec file. Treat stage files marked `implemented` or `in progress` as context for cross-file checks, but focus the assessment strictly on stage specs that have the status `planned`. Cross-reference the framework against the assessment dimensions defined in the framework_assessment reference.

Produce the assessment output in the exact format the reference specifies: a general assessment paragraph followed by a severity-ordered issue list. Stop after presenting the list. Do not fix anything.
